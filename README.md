     * সর্বমোট প্রোডাক্ট (All)
     * এক্টিভ প্রোডাক্ট (Active)
     * ডি-এক্টিভ প্রোডাক্ট (Inactive)
     * লো স্টক প্রোডাক্ট (Low Stock, <= 5)
   - যেকোনো কাউন্টার কার্ডে ক্লিক করলেই টেবিল তাৎক্ষণিক ফিল্টার হয় এবং কাউন্টারগুলো স্বয়ংক্রিয়ভাবে আপডেট হয়!

   - প্রোডাক্ট যোগ, এডিট, ৫-১০টি ছবির লিংক ও ডিলিট অপশন।

6. **স্মার্ট অর্ডার ম্যানেজমেন্ট (`admin.html`):**  
   - **সকল স্ট্যাটাস অনুযায়ী অন-ক্লিক কাউন্টার ফিল্টার কার্ড:**
     * সব অর্ডার (All Orders)
     * নতুন / পেন্ডিং (Pending)
     * কনফার্মড (Confirmed)
     * প্রসেসিং (Processing)
     * কুরিয়ারে পাঠানো (Shipped)
     * ডেলিভারড (Delivered)
     * বাতিল (Cancelled)
   - স্ট্যাটাস পরিবর্তন, গ্রাহকের নাম, ফোন, ঠিকানা ও অ্যাডমিন নোট এডিট করার মোডাল।
   - অফিশিয়াল চালান/ইনভয়েস প্রিন্ট ও CSV ডাউনলোড।

8. **প্রি-লোডেড ২০টি অফিস ইকুইপমেন্ট প্রোডাক্ট:**

## 🚀 গিটহাব পেজেস-এ পাবলিশ করার নিয়ম (GitHub Pages Deployment)

1. [GitHub](https://github.com)-এ একটি নতুন রিপোজিটরি তৈরি করুন (যেমন: `dream-cart-bd`)।
2. আনজিপ করা ফোল্ডারের ফাইলগুলো আপলোড করুন:
   ```text
   index.html
   admin.html
   README.md
   css/
     └── style.css
   js/
     ├── data.js
     ├── app.js
     └── admin.js
   ```
3. রিপোজিটরির **Settings** > **Pages**-এ যান।
4. **Build and deployment** সেকশনে Branch: `main` এবং Folder: `/(root)` নির্বাচন করে **Save** দিন।
5. ১-২ মিনিটের মধ্যেই সাইট লাইভ হয়ে যাবে। অ্যাডমিন ডিফল্ট পিন: `1234`।
